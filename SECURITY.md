# Security policy

The latest release is supported. AwakeBar does not collect user data or use network services.

Report suspected vulnerabilities privately through [GitHub vulnerability reporting](https://github.com/Charlisim/AwakeBar/security/advisories/new). Avoid public exploit details until a fix can be evaluated.

Power assertions are temporary. AwakeBar does not change lock preferences, bypass authentication, or unlock a Mac. Managed policies remain authoritative.
